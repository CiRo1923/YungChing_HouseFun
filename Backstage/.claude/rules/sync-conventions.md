# 規範複本一律完全複製

**優先順序:第 2 順位**,與「動手之前先讀一次規範」同級。
低於「無法判斷就一律問」—— 同步時遇到判斷不出來的地方照樣停下來問。

`.claude/rules/`、`.claude/skills/`、`.claude/hooks/`、`.tools/lint/`、`.githooks/`
這幾處是另一份規範的複本。

**同步就是完全複製。** 來源目錄底下的每一支,整份覆蓋過來,一個字都不改。

這不是原則性的說法,是字面上的:複製完之後,這邊與來源同名的每一支檔案,
**逐位元組相同**。做完一定要用這個標準驗一次,有任何一支對不上就是還沒做完。

## 為什麼不能只複製一部分

複本的價值在於「兩邊真的一樣」。一旦這邊自己改過,就再也說不出
「同步完成」是什麼意思:差異到底是對方新增的,還是這邊當初改的?
沒有人分得出來,而分不出來的那一天起,同步這件事就失去意義了。

## 一、每一次都重新讀來源的每一支檔案,比對整份內容

用來源目錄的實際內容跑一遍,**不要憑記憶、不要用上一輪的比對結果、
也不要看檔案的修改時間判斷「這支沒動過」**。
對方可能在上一個指令之後才改,而修改時間相同不代表內容相同。

不要自己列一份「要比對哪幾支」的清單 —— 那份清單會過期,
而漏掉的那一支不會有任何徵兆,只會讓人以為「那邊還沒做」。

**比對的是整份檔案的內容,不是只看匯出的名稱。**
只比名稱的話,這幾種差異一個都看不到,而它們都會改變行為:

| 看不到的差異 | 為什麼名稱比對掃不到 |
| --- | --- |
| 同名的函式裡面換了判斷 | 名字一樣,規則已經不同 |
| 常數、正則、清單的內容變了 | 那些沒有匯出,名稱清單裡不會出現 |
| 提示訊息與註解改了 | 那是給人看的說明,改了要跟著更新 |
| 新增或刪掉的私有輔助 | 不匯出,所以看不到 |
| 測試案例的內容變了 | 自我驗證跟著規則走,少了就測不到新規則 |

做法是整個目錄逐支比對整份內容,**來源有而這邊沒有的檔案也要一起複製過來**,
新增的規則檔與 skill 最容易在這一步漏掉。

## 二、整份覆蓋,不做任何改寫

複製就是複製。**不要**在複製之後做這些事:

- 改名字讓它接得上這邊的舊叫法
- 把這邊多出來的函式接回檔尾
- 補一段判斷讓它適用這邊的寫法
- 為了讓它能跑而調整呼叫端
- 只挑「看起來需要的」那幾支複製

那些都是自己改寫,做了就回到上面說的分不出差異的狀態。
**複製之後接不上的話,那是要回報的事實,不是要就地解決的問題。**

## 三、必須不同的地方一律列出來問

複製完跑一次驗證。有東西壞掉、或是有地方**非得不同不可**,
把它列出來問開發者,不要自己決定怎麼處理。

列的時候要寫清楚三件事:**哪一支檔案、複製之後實際發生什麼、
不同的話要改哪一行**。附上工具的實際輸出,不要只寫「會有問題」。

設定檔(`.tools/lint/project-config.mjs`)也是一樣 ——
它的值確實要跟著專案走,但**改之前先問過開發者**,
改了哪幾項也要講出來。

## 不在複本範圍內的幾支

這幾支是這個專案自己的,**已經確認過保留**,不必跟來源比對,
也不要在每一輪同步時重新列出來問一次:

| 檔案 | 為什麼是這個專案自己的 |
| --- | --- |
| `.tools/lint/diff-output.mjs` | 比對建置產物的 CSS,來源沒有這個指令 |
| `.claude/hooks/sync-conventions.cjs` | 這條規則的提醒本身 |
| `.claude/rules/sync-conventions.md` | 這份文件 |
| `.claude/rules/` 底下記錄待辦的那幾份 | 待辦是這個專案的進度,不是規範 |
| `.claude/skills/` 底下講專案功能的那幾支 | 錯誤頁、彈窗、路由、共用元件同步、日期選擇器、相片排序、捲軸留白那些,講的是這個專案怎麼運作 |

判斷方式:**它講的是「規範怎麼寫」還是「這個專案怎麼運作」?**
前者要跟來源一致,後者是這個專案自己的內容,來源本來就不會有。

新增這類檔案時補進上面這張表 —— 沒補的話,下一次同步會把它當成
「要回報的差異」重新列出來,而那個問題上一次已經回答過了。

## 驗證

複製完依序跑這三件事,全部通過才算做完:

1. **逐支比對** —— 與來源同名的每一支都要逐位元組相同
2. **`npm run lint:css`** —— 看掃描檔案數與前提檢查。
   掃描數突然變少、或出現「有 N 項前提不存在」,就是設定與這個專案對不上
3. **`npm run test:css`** —— 規則的自我驗證

第 2、3 項沒過的話,**先確認是哪一支檔案造成的再回報**,不要直接動手修。

## 自動提醒

寫入複本範圍內的檔案時,`.claude/hooks/sync-conventions.cjs` 會把上面幾件事
帶進對話。它只提醒、不阻擋 —— 擋下來只會讓人想繞過。
