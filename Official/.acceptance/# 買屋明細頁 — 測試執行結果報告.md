## 二、🔴 測試回報

### D-01 網址與 Canonical 缺少結尾斜線

- <strong>規格</strong>：網址結尾都要用 `/` 結束，例如 `www.housefun.com.tw/buy/{物件ID}/`
- <strong>實際</strong>：`https://www.housesfunlab.com/buy/house/6591494`（無結尾 `/`）；canonical 同樣無結尾斜線
- <strong>問題</strong>：URL 與 canonical 都缺少結尾 `/`

---

### D-02 Title 調整

- <strong>規格</strong>：`{地區}{型態}{房數}{坪數} |{縣市}+{路段}或{社區名} | {總價} | 好房網HouseFun`
  - 範例(無社區)：`仁武區3房透天厝/別墅45.2坪 | 高雄市勇全路 | 1968萬 | 好房網HouseFun`
  - 範例(有社區)：`仁武區3房透天厝/別墅45.2坪 | 高雄市堅山景仰 | 1968萬 | 好房網HouseFun`
- <strong>實際</strong>：`@必賣! 雅江首藏 一樓庭院裝潢戶私人獨立大車庫 | 萬華區買房 | 好房網HouseFun`

---

### D-03 Meta Description 缺少生活機能摘要

- <strong>規格</strong>：`{縣市}{地區}{路段}{社區名稱}的待售物件，總價{%n}、單價{%n}，{建物坪數}、{格局}，{生活機能摘要}`
  - 範例：`...步行5分鐘到捷運信義安和站，10分鐘到捷運大安站，3分鐘到便利商店。`
- <strong>實際</strong>：`台北市萬華區雅江街雅江首藏的待售物件，總價 5200 萬、單價 124.02 萬/坪，41.93坪，3房 0廳 2衛。`
- <strong>問題一</strong>：缺少結尾的生活機能摘要（步行到捷運站、便利商店等）
- <strong>問題二</strong>：格局顯示 `3房 0廳 2衛`，廳為 0 時應以 `--` 呈現或省略，而非顯示 `0廳`

---

### D-04 H1 為空

- <strong>規格</strong>：頁面應有正確的 H1 標籤
- <strong>實際</strong>：`<h1>` 標籤存在但<strong>內容為空</strong>，案名以 `<h2>` 顯示
- <strong>問題</strong>：H1 無內容，SEO 缺失；H2 被用來承載案名語意不正確

---

### D-05 麵包屑 URL 格式不符規格

- <strong>規格</strong>：
  - 買屋：`www.housefun.com.tw/buy/`（不帶任何條件）
  - 縣市：`www.housefun.com.tw/buy/{縣市ID}/`
  - 區域：`www.housefun.com.tw/buy/{區域ID}/`
- <strong>實際</strong>：
  - 買屋 → `/buy/list/01_region/?pg=1`（含 list 路徑與 query param）
  - 台北市 → `/buy/list/01_region/?pg=1`（縣市與買屋同一連結，應不同）
  - 萬華區 → `/buy/list/01011_region/?pg=1`（含 list 路徑）
- <strong>問題</strong>：麵包屑連結格式與規格不符，含 `list` 路徑段與 `?pg=1` 參數

### D-13 og:image URL 缺失（物件有封面照仍未輸出）

- <strong>規格</strong>：og:image 為物件封面照；若無封面照則顯示全站預設 og 圖
- <strong>實際</strong>：物件 6639097 有實際照片（API `media.images` 有值），但頁面僅輸出 `og:image:type`、`og:image:width`、`og:image:height`，缺少 `og:image` URL；`og:image` URL tag 完全不存在
- <strong>問題</strong>：封面照未寫入 og:image，社群分享無法顯示物件圖片（原 Q-01 確認為缺陷）

### D-14 基本資料樓層顯示 `null`

- <strong>規格</strong>：樓層欄位顯示物件所在樓層及總樓數，格式如 `13 / 24 樓`；僅單樓時不顯示範圍
- <strong>實際</strong>：`floor.to` 為 null 時，顯示為 `13 ~ null / 24 樓`
- <strong>問題</strong>：`null` 值未過濾，直接拼入文字輸出；單層物件應顯示 `13 / 24 樓`，不帶 `~ null`

---

### D-15 法定用途顯示代碼而非文字

- <strong>規格</strong>：基本資料「法定用途」欄位顯示對應文字（如「住宅」、「商業」）
- <strong>實際</strong>：API 返回 `caseUsageToken: "1"`，頁面直接顯示 `1`，未對應轉換為可讀文字
- <strong>問題</strong>：代碼未轉換，使用者無法理解欄位含義

---

### D-16 管理費顯示原始格式 `4127 / 1`

- <strong>規格</strong>：管理費欄位依繳費週期顯示，月繳格式為「月繳 N 元」或「N 元/月」
- <strong>實際</strong>：頁面顯示 `4127 / 1`（API 欄位 `caseManageFee: 4127`、`caseManageFeePeriodToken: "1"`），`/ 1` 為期別代碼，未轉換為可讀文字，且金額無千分位格式化
- <strong>問題</strong>：管理費格式未處理，影響可讀性

### D-17 無資料欄位仍顯示空白標籤（加蓋格局 / 朝向 / 無障礙空間）

- <strong>規格</strong>：當沒有資料時，該欄位不顯示，後方同區塊的資料自動向前遞補
- <strong>實際</strong>：基本資料中「加蓋格局」（features 空陣列）、「朝向」（caseFaceToken: null）、「無障礙空間」（caseBarrierfreeToken: ""）均顯示欄位標籤但值為空，未隱藏
- <strong>問題</strong>：空值欄位應整列隱藏，目前保留空白標籤，版面出現無意義的空行

### D-18【RWD】手機版導覽列隱藏但無漢堡選單按鈕

- <strong>問題</strong>：手機用戶無法展開主導覽，所有頂部連結（買屋 / 社區 / 新建案 / 實價登錄 / 租屋 / 新聞）在手機版完全不可及
- <strong>影響範圍</strong>：全站共用 Header，列表頁（C101-2）與明細頁同步受影響

### D-19【RWD】明細頁各 section 區塊在手機寬度下左右 margin 不一致

## 五、補充說明

### 格局「0廳」顯示問題（跨頁面）

明細頁 Description 及基本資料中出現 `3房 0廳 2衛`。依規格，無資料或為 0 時應顯示 `--`（如 `3房--廳2衛`）。此問題同時影響列表頁卡片顯示，建議統一處理。

### 照片問題（第二輪重測 6639097）

第二輪以有照片的物件 6639097 重測：

- 物件主圖仍顯示系統吉祥物圖（黃色鴨子），非實際物件照片；圖片計數顯示 `1 / 1`
- API `media.images` 有真實照片 URL（fps-t.hfcdn.com），但前端未載入
- 推測照片 CDN 在測試環境未開放，或前端圖片載入邏輯有誤
- D-07（照片未載入）、D-08（WebP 格式）問題在第二輪仍存在，與 D-13（og:image）同源

### og:image 技術說明

頁面已輸出 `og:image:type="image/jpeg"`、`og:image:width="1200"`、`og:image:height="630"` 等 sub-property，但缺少最關鍵的 `og:image` URL tag，導致社群分享無法抓取物件封面。
